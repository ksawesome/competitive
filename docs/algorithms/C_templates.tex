\chapter{Template Index}\label{ch:templates}

Every template in the library, grouped as in \file{library/}, with its keyboard chord, its snippet prefix and the page of
this book that explains it. Press the chord (\key{Ctrl+Alt+T}, \key{Ctrl+Alt+Y} or \key{Ctrl+Alt+U}, then the key) or
type the prefix and \key{Tab} to paste it at the cursor; GUIDE.pdf has a card for each one with its usage. The table is
generated from the library itself by \texttt{python tools/cp.py docs}, so it is always complete.
